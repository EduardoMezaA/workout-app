# Misión

## Qué construimos

WorkoutApp es una aplicación web de rutinas de ejercicio personalizado enfocada exclusivamente en ganar fuerza y masa muscular. El usuario elige los grupos musculares y el equipamiento disponible, y la app genera una rutina estructurada con calentamiento, ejercicios, descansos temporizados y estiramientos.

1. **Generador de rutinas** — selección de grupos musculares y equipamiento, asignación aleatoria de ejercicios predefinidos por el admin para evitar monotonía.
2. **Rutina activa** — guía paso a paso con timer de descanso, stopwatch acumulativo, registro de peso opcional y fases claras: calentamiento → ejercicios → descanso → estiramientos.
3. **Bitácora de progreso** — registro histórico de sesiones con ejercicios realizados, series, reps, peso y tiempo total, para que el usuario pueda ver su evolución.

## Para quién

- **Usuario principal** — persona que entrena para ganar fuerza/masa muscular y quiere una rutina estructurada sin tener que planearla desde cero cada vez.
- **Administrador (autor)** — único responsable de agregar, editar y eliminar ejercicios, grupos musculares e imágenes/GIFs demostrativos.

## Principios

- **Simple primero** — la interfaz debe ser clara y directa, sin fricción entre "quiero entrenar" y "empezar rutina".
- **Sin distracciones durante el entreno** — la pantalla de rutina activa es la experiencia central; debe funcionar sin que el usuario tenga que pensar.
- **Contenido controlado** — los ejercicios solo los agrega el admin, garantizando calidad y consistencia.
- **Progreso visible** — el usuario debe poder ver fácilmente cómo ha mejorado con el tiempo.
- **Mobile-first** — la app se usa principalmente desde el celular durante el entreno; el diseño prioriza pantallas pequeñas.

## Qué NO es

- No es una app para bajar de peso ni para cardio — el enfoque es exclusivamente fuerza/masa muscular.
- No es una red social — no hay perfiles públicos, no hay compartir rutinas entre usuarios, no hay rankings.
- No permite que los usuarios creen o modifiquen ejercicios — eso es exclusivo del admin.
- No es un sustituto de un entrenador personal — no adapta la rutina según historial de lesiones ni hace periodización avanzada.
- No tiene planes de pago ni suscripciones — es un proyecto personal.
